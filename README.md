# Chayma Jhabli’s portfolio

This portfolio presents Chayma’s experience in data engineering, machine learning, and analytics. English is the default site language. Visitors can switch to French or Arabic.

## Run locally

```sh
npm install
npm run dev
```

To verify a production build, run `npm run build` followed by `npm run preview`.

## Edit the portfolio

The site content follows [Chayma’s résumé](docs/chayma_resume.md). Edit navigation in `public/data/categories.json` and `public/data/sections.json`, then update the content and its three translations in `public/data/sections/`. The profile, site languages, and shared interface text are managed in `public/data/profile.json`, `public/data/settings.json`, and `public/data/strings.json`.

The résumé button opens the [English PDF](public/pdf/chayma-jhabli-resume.pdf) based on the Markdown résumé. The name pronunciation button uses the English recording in English and French and the Arabic recording in Arabic.

## About

This template was created by and is maintained by **[Ryan Balieiro](https://ryanbalieiro.com/)**.

Additional frameworks and plugins used include:
- **Smooth Scrollbar**: A customizable scrollbar plugin.
- **Swiper**: A powerful library for creating touch sliders.
- **EmailJS**: A free service that allows you to send emails using JavaScript.
- **Font Awesome**: A library of free vector icons.
- **PrimeIcons**: A collection of premium line icons.
